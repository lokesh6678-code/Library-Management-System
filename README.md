# Library Management System

A Java-based application designed to manage library book records efficiently.

## Features
- Add new books
- View all books
- Search books by ID
- Borrow books
- Return borrowed books
- Check book availability
- Prevent duplicate book IDs

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Scanner

## How to Run
1. Install Java JDK.
2. Compile using: javac LibraryManagementSystem.java
3. Run using: java LibraryManagementSystem
